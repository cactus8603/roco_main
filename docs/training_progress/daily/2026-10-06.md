# Progress Update — 2026-10-06

## Completed evidence

The uncertainty-aware SEA-RAFT refinement finished training with an internal
validation EPE of `1.1444`, compared with `3.1829` for the pretrained baseline.
This corresponds to an approximately `64.0%` relative reduction under the same
validation protocol.

The selected checkpoint also improved uncertainty ranking and calibration:
AUSE `0.01764`, severe-error AUROC `0.98900`, and calibration MAE `0.06698`.

An input/output scale audit confirmed that RGB is converted from `[0,1]` to
`[0,255]` exactly once before SEA-RAFT normalization, while predicted and
ground-truth flow remain in pixel units. The measured improvement is therefore
not a learned scale conversion.

## Interpretation

The result is strong evidence within the current three-scene crop protocol,
but it is not an official Sintel test result. A full-resolution Clean/Final
comparison against the same pretrained baseline is running and will determine
whether the gain transfers to the standardized setting.

The SAM-guided model has not produced a validation result yet, so no positive
SAM claim is recorded.

Existing WAFT evidence remains relevant only to the earlier selective-repair
mechanism: it confirms strong error localization and positive frozen repair
gain, but does not yet replicate the new training method.
