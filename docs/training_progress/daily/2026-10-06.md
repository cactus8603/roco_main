# 2026-10-06 證據紀錄

## U2-main：最重要的新結果

U2-main 在內部三場景 Clean+Final validation 上得到最佳 EPE `1.355602`。相較同一
protocol 的 raw Spring-M `3.182911`，相對下降約 `57.4%`。

改善不是由初始化直接取得：U1 best 為 `3.172267`，U2 第一次 validation 為
`3.171271`。目前證據較支持「交替 observer/flow 訓練產生改善」，而非單純載入
pretrained/refiner weights。

## 最佳值的可信度與限制

- epoch index 9：EPE `1.355645`
- epoch index 10：EPE `1.355602`

相鄰兩輪只差約 `0.00004`，最佳值不是明顯的單輪孤立尖峰。另一方面，epoch 11–14
退化至 `1.46–1.56`，epoch 15–16 又恢復至約 `1.414`，證明訓練並不單調，最終應報
best checkpoint 而非 last checkpoint。

最佳 EPE epoch 的 AUSE / calibration MAE 為 `0.019579 / 0.074043`；epoch 16 的 AUSE
更低（`0.018535`），epoch 12 的 calibration MAE 更低（`0.068332`），但兩者 EPE 均
較差。這是 accuracy、uncertainty ranking、calibration 必須分開選擇與報告的直接證據。

## SAM：目前證據邊界

SAM segmentation、資料完整性檢查、regional homography loss 與後續 U2-SAM → 9A-SAM
流程已具備；segmentation 為 1,029 / 1,348 frames。因尚未有 U2-SAM validation，今天
只記錄「實驗已可執行」，不把它寫成正面效果。

## WAFT：已知結果與新管線缺口

既有 frozen WAFT/KITTI confirmation 顯示 equivariance discrepancy 的 error-localization
AUROC/AP 為 `0.8601/0.8112`，candidate-direction AUROC 僅 `0.4844`。這支持風險定位，
但否定用 disagreement 直接選 action。

WAFT frozen hard selector 的 clean/corrupt gain 為 `+0.2819/+0.2610 px`，corrupt gain 的
95% CI 為 `[0.1520, 0.4137]`，worst harm `0.1489 px`，通過 frozen gates。這是既有
selective repair 的有效跨-backbone證據。

新的 U2/SAM WAFT adapter 雖已實作，但尚未固定 checkpoint，也沒有 WAFT-specific U0/U1
與同口徑 U2 訓練，所以目前不得把舊 WAFT 結果解讀為新 U2/SAM 已複現。
